# Learn Playwright Batch 2X

This repository contains learning materials and examples for Playwright automation testing framework.

## Project Structure

- **chapter_01_Basics/**: Basic concepts and setup
- **chapter_02_Javascript_Concept/**: JavaScript fundamentals
- **chapter_03_Identifier_Literals/**: Identifiers, literals, and naming conventions
- **chapter_04_Javascript_Concepts/**: `var`, `let`, `const`, hoisting, and function scope examples
- **chapter_05_Literal/**: Template literals, string literals, null/undefined, and number literal examples

## Prerequisites

- Node.js installed
- Playwright installed (`npm install -g playwright`)

## Running Tests

Navigate to a chapter folder and run:

```bash
npx playwright test
```

## Running JavaScript Examples

To run the JavaScript concept files directly:

```bash
cd chapter_04_Javascript_Concepts
node 09_var_let_const.js
```

For Chapter 05 literal examples:

```bash
cd chapter_05_Literal
node 29_Backtick_Single_Double.js
```

You can replace the file name with any other `.js` file in the folder.
