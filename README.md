# Learn Playwright Batch 2X

This repository contains JavaScript practice files and learning notes organized by chapter. It is designed to help you explore core programming concepts and basic Node.js execution.

## Project Structure

- [chapter_01_Basics](chapter_01_Basics/README.md): Basic JavaScript syntax and first scripts
- [chapter_02_Javascript_Concept](chapter_02_Javascript_Concept/README.md): Core JavaScript fundamentals
- [chapter_03_Identifier_Literals](chapter_03_Identifier_Literals/README.md): Identifiers, literals, and comments
- [chapter_04_Javascript_Concepts](chapter_04_Javascript_Concepts/README.md): Variables, functions, scope, and hoisting
- [chapter_05_Literal](chapter_05_Literal/README.md): Template literals, strings, numbers, and null/undefined
- [chapter_06_Operator](chapter_06_Operator/README.md): Arithmetic, comparison, logical, and ternary operators
- [chapter_07_If_else](chapter_07_If_else/README.md): Conditional statements and decision-making examples
- [chapter_08_Switch_Statement](chapter_08_Switch_Statement/README.md): Switch-case logic and examples
- [chapter_09_UserInput](chapter_09_UserInput/README.md): Reading input from the user in Node.js
- [chapter_10_Loops](chapter_10_Loops/README.md): For loops, while loops, do-while loops, and loop control statements

## Prerequisites

- Node.js installed on your machine
- Optional: Playwright installed with `npm install -g playwright`

## Running JavaScript Examples

Run any example directly with Node.js:

```bash
cd chapter_04_Javascript_Concepts
node 09_var_let_const.js
```

You can replace the file name with any other `.js` file in the folder.
